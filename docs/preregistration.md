# Пререгистрация и план анализа

Фиксируется **до** подтверждающего прогона. Старые 189 сделок — пилот и
исследовательский анализ, не подтверждающий результат.

## 1. Гипотезы

**Первичные (подтверждающие):**

- **H1.** Доля пробоев положительна и различается между моделями.
- **H2.** Разброс уровня риска между бэкбонами превышает разброс между персонами
  внутри бэкбона.
- **H4.** Дисперсия числа пробоев на сессию превышает биномиальную: существует
  общий фактор (`realized_rho > 0`).

**Вторичные (exploratory, помечаются как таковые):**

- **H3.** Гетерогенность уровня риска между моделями (описательно; это **не**
  монокультура).
- **H5.** Парная реализованная ρ по бэкбонам согласуется с предсказанной из
  исследования 1.
- **H6–H8.** Стадность, концентрация контрагента, деградация мандата.

## 2. Основные метрики

| Область | Метрика |
| --- | --- |
| Исследование 1 | доля пробоев (Уилсон + кластерный бутстрэп по бэкбонам), `p_hat` с интервалами |
| Исследование 1 | out-of-sample log-loss/Brier (leave-one-backbone-out, leave-one-opponent-out), ECE |
| Исследование 1 | `interaction delta` (аддитивная модель против модели с взаимодействием) |
| Исследование 2 | `realized_rho` + `rho_p_value`, эффект дизайна (`portfolio` против `control`) |
| Исследование 2 | ES портфеля, `realized_n_eff` |
| Служебные | compliance, границы Мански, `finish_reason`, стратум `repaired` |

## 3. Правила исключения

- `protocol_fail` не исключаются молча: основной анализ по `protocol_ok`,
  чувствительность — по границам Мански.
- Сделки с `repaired` — отдельный стратум.
- Вырожденные маргиналы дают `nan` и отдельный счёт; они не превращаются в ноль.
- Запрещено удалять сделки ради более «красивой» картины.

## 4. Множественные сравнения

- Первичные (H1, H2, H4) — поправка Холма.
- Вторичные — без поправки, с явной пометкой exploratory.

## 5. Обучающая и тестовая части

- Прогноз `q` для e-процесса — только по обучающим условиям (`eprocess_oos`).
- Внешняя проверка — leave-one-backbone-out, leave-one-opponent-out,
  leave-one-scenario-out.
- Оценок на обучающих данных в отчёте нет.

## 6. Объём и мощность

- Исследование 1: `K >= 5` прогонов на агента, минимум 2 бэкбона для
  внутри-групповой ноги.
- Исследование 2: `R >= 60` сессий на условие (при `R = 20` ошибка ρ ≈ 0.09),
  плюс контрольная рука с теми же маргиналами.

## 7. Решающие правила

- **H1** подтверждается, если нижняя граница Уилсона доли пробоев > 0 минимум на
  двух бэкбонах.
- **H2** подтверждается, если различие бэкбонов значимо после Холма и интервал
  уровня персоны уже ±0.05; иначе это «нет доказательств эффекта персоны», а не
  «эффекта нет».
- **H4** подтверждается, если `realized_rho > 0`, `rho_p_value < 0.05` и эффект
  дизайна > 1.
- Отрицательный результат публикуется наравне с положительным.

## 8. Фиксируется до прогона

- Коммит кода и хэш промптов (`git_sha`, `prompt_hash`).
- Список моделей, вендор, размер, открытость и режим reasoning.
- Сценарии, стратегии и лестницы противников.
- Версии зависимостей.

## 9. Открытые риски

- Нестационарность бесплатных провайдеров (пишется `served_model` и дата).
- Скриптованный противник занижает риск; нужен адаптивный LLM-противник.
- Одна ось (цена); сроки и штрафы — расширение.
- Стадность и общий фактор разделяются лишь частично.
